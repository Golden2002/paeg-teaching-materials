- 细胞呼吸
  - 概念与场所
    - 定义：有机物氧化分解、释放能量
    - 主要场所：线粒体
    - 反应物：葡萄糖、氧气
    - 产物：CO₂、H₂O、ATP
  - 有氧呼吸
    - 第一阶段：糖酵解
      - 场所：细胞质基质
      - 产物：丙酮酸、[H]、少量ATP
    - 第二阶段：柠檬酸循环
      - 场所：线粒体基质
      - 产物：CO₂、[H]、少量ATP
    - 第三阶段：电子传递链
      - 场所：线粒体内膜
      - 产物：H₂O、大量ATP
  - 无氧呼吸
    - 特点：不需氧气、释放能量少
    - 类型一：乳酸发酵
      - 产物：乳酸
      - 实例：动物肌肉细胞
    - 类型二：酒精发酵
      - 产物：酒精 + CO₂
      - 实例：酵母菌、植物根
  - 能量代谢
    - ATP生成方式：底物水平磷酸化、氧化磷酸化
    - 能量去向：热能散失、储存于ATP
    - 总反应式：C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + 能量
  - 影响因素与应用
    - 影响因素：温度、O₂浓度、CO₂浓度、水分
    - 应用实例：酿酒、制醋、食品保鲜、剧烈运动
